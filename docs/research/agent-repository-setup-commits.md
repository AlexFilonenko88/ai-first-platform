## Recommendation

Use the repository-hygiene baseline from `d3523c1`, curate only the agent skills that support the current product work from `44c9477`, and treat `dd1a104` as a reminder to keep agent entry points minimal. These are patterns to adapt, not a package to copy wholesale. ## `d3523c1` — prepare repository for development

**Changes.** This commit adds `.editorconfig`, `.gitattributes`, `.gitignore`, a Russian README, and customer requirements; it introduces no application code or selected stack. The README says the stack, architecture, and agent connection remain open, and that implementation, tests, and CI will follow later. [Commit diff](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced) [README at this commit](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/README.md#L14-L34)

**Explicit rationale.** The attributes file says it normalizes text to LF, preserves CRLF for Windows batch files, and marks common image, font, archive, and PDF formats as binary. The ignore file separates local editor state, environment and credential files, dependencies, generated output, reports, and temporary files. The README asks contributors to keep lockfiles, use local `.env` files and example files without real values, and add setup and check instructions with their code. [`.gitattributes`](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/.gitattributes#L1-L18) [`.gitignore`](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/.gitignore#L1-L61) [README](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/README.md#L22-L34)

**Likely rationale — inference.** These files establish shared cross-platform formatting, reduce accidental commits of local or generated files, and record contributor expectations before implementation starts. The commit does not state these motivations as a separate design rationale; they follow from the configuration and README contents. [Commit diff](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced)

## Synthesis for the project owner

1. **Adopt repository hygiene, not a framework.** Keep portable formatting and safe environment-file rules, then tailor them after choosing the stack. [Bootstrap configuration](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced) [Target MVP requirements](https://github.com/AlexFilonenko88/ai-first-platform/blob/ca49c60397752c1634bee7bf3bee779325258152/customer-requirements.md#L15-L25)
2. **Curate agent practices around real work.** Domain terms, public test boundaries, and review can support clear boundaries and shared development practices; add skills when they solve an observed need. [Domain-modeling skill](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/domain-modeling/SKILL.md#L40-L74) [TDD skill](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/tdd/SKILL.md#L8-L24) [Target future directions](https://github.com/AlexFilonenko88/ai-first-platform/blob/ca49c60397752c1634bee7bf3bee779325258152/customer-requirements.md#L29-L39)
3. **Keep instructions separate from authorization.** The target explicitly requires employee and agent access to match and to stop after employee offboarding; implement those controls in the platform's access model, not only in agent guidance. [Target access requirements](https://github.com/AlexFilonenko88/ai-first-platform/blob/ca49c60397752c1634bee7bf3bee779325258152/customer-requirements.md#L19-L23)
4. **Prefer one source of truth, with verified compatibility.** The commits show a canonical agent-guidance file and later removal of one redundant Claude link, but client discovery remains tool-specific.
