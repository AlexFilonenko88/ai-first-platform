# Модуль «Аудит» получает события через RabbitMQ

**Status**: accepted

Первая версия должна показывать администраторам единый журнал событий из нескольких модулей. Модуль «Аудит» владеет записями журнала, а другие модули передают события через transactional outbox, RabbitMQ и inbox по ADR-0003. Поскольку аудит входит в первую версию, RabbitMQ запускается в Docker Compose.

## Последствия

- Запись содержит событие, инициатора, затронутую учётную запись, проект или репозиторий, время и результат.
- События аудита не содержат секреты, исходный код или логи агента.
- Модуль «Аудит» принимает повторно доставленные события идемпотентно.
